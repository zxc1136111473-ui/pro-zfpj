# ZeroForwarder 1.2.0 二进制逆向结论

> 2026-10-05 获取 zf-1.20.zip(109MB 离线包),逆向出 1.2.0 版二进制。
> 解决的问题:1.1.67 端点与控制面 1.2.0 的 **WebSocket Pong 心跳协议不兼容**(1.1.67 不响应 Pong → 被 Pong watchdog 每 21s 踢下线,面板显示离线)。

## 二进制清单(bin-1.2.0/)

| 文件 | 版本 | 大小 | 用途 |
|---|---|---|---|
| `forwarder-server-x86_64` | forwarder-server 1.2.0 | 44.9MB | 转发端点二进制(连控制面, 监听 3697) |
| `zf-worker-x86_64` | zfw-server 1.2.0 | 78.3MB | 服务器节点二进制(被 controler 管理) |

来源:官方离线安装包 `forwarder-server-offline-{arch}.sh` + `zf-worker-offline-{arch}.sh`
(自解压脚本, `__PAYLOAD_START__` 标记后为 tar.gz payload)。

## 离线包结构(逆向)

```
*.sh (Bash 自解压)
  ├── 头部 shell: 架构检测 / NTP 检查 / systemd 安装 / 从控制面下载逻辑
  ├── __PAYLOAD_START__
  └── tar.gz: server (ELF static stripped) + config.json
```

- forwarder config.json 字段: bind / dual_stack / password / obfs / relay_method /
  token_id / web_api_url / ws_privkey / web_pubkey / dynamic_ip
- worker config.json 字段: mgmt_arranger_public_key / mgmt_upgrade_url /
  mgmt_ws_endpoint / mgmt_hammer_proxy / enable_remote_shell / stats / backends
- worker 二进制内置名 `zf-worker-1.2.0`(版本铁证)

## 关键差异(1.1.67 → 1.2.0)

| 点 | 1.1.67 | 1.2.0 |
|---|---|---|
| WS 心跳 | 无 ping/pong 响应 | 响应 Pong watchdog(web 侧 90s 超时踢线) |
| 版本报告 | `forwarder-server 1.1.67` | `forwarder-server 1.2.0` |
| worker 名 | zf-worker | zfw-server 1.2.0 |

## 部署状态(89.58.7.134 控制面)

- ✅ zfc-web `/app/downloads/server` = 1.2.0(面板分发即 1.2.0)
- ✅ `/app/downloads/server-arm64` = 1.2.0(消除 arm64 下载 404 噪音)
- ✅ `/opt/zf/worker/zf-worker` = zfw-server 1.2.0
- ✅ 下载验证: `GET /api/forwarder/download/{token}/server?arch=x86_64` → 200 + 1.2.0

## 端点升级

美国机器(216.167.26.37)端点需从 1.1.67 升到 1.2.0,升级脚本在控制面:
```bash
# 在端点机器执行
bash <(curl -s https://zf.artusx.com/tools/upgrade_fwd.sh)
```
或面板端点页面重新获取安装命令重装。
